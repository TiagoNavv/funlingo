# FunLingo — Aprendendo Inglês Brincando

Plataforma web gamificada para ensino de inglês voltada para crianças, com vocabulário, quizzes, histórias narradas e acompanhamento de progresso.

🔗 **Acesse:** https://funlingo-english.vercel.app/

## Sobre o projeto
Projeto em grupo (3 integrantes), desenvolvido como parte da graduação em Engenharia de Software (UNAERP). Liderei a concepção e a direção do projeto — definição de funcionalidades, estrutura, conteúdo pedagógico e identidade visual — e realizei o deploy da aplicação.

## Funcionalidades
- Vocabulário com pronúncia em áudio
- Quizzes temáticos com sistema de XP e sequência (streak)
- Histórias narradas com quiz de compreensão
- Desafio diário
- Acompanhamento de progresso

## Tecnologias
- HTML5 e CSS3
- API de síntese de voz (áudio)
- Deploy via Vercel

## Desenvolvimento
O código foi implementado com apoio do Claude Code (ferramenta de IA para desenvolvimento), sob minha direção de produto e revisão. Isso me permitiu focar em decisões de funcionalidade, UX e conteúdo pedagógico, enquanto aprendia na prática o processo de deploy e versionamento com Git/GitHub.
